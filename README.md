# Cinema+ — Cinema Ticketing Platform

A responsive, multi-page website created for the Web Technologies midterm project. Cinema+ presents movies and a demo ticket-booking process.

**Team:** Kudaibergen Temirlan and Serikov Sunggat.

## Pages

- Home
- Movies
- Movie Details
- Seat Selection
- Checkout

## Features

- Shared navigation and a minimalist design.
- Semantic HTML, movie posters, a movie information table, and forms.
- CSS Flexbox, Grid, and positioning.
- Responsive layouts with tablet and mobile media queries.
- Local Bootstrap files, grid system, and utility classes.

## How to Open

Open `cinema-ticketing/index.html` in a browser. No installation is required.

## Demo Limitations

The project uses HTML, CSS, and Bootstrap without JavaScript. Seat selection, ticket quantities, filtering, and checkout are static demonstrations. No real bookings or payments are processed.
