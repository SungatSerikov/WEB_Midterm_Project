# WEB_Midterm_Project — Cinema+

Учебный Cinema Ticketing Platform для midterm по Web Technologies.
Команда: Kudaibergen Temirlan и Serikov Sunggat.

## Готовая страница

Откройте `cinema-ticketing/index.html` в браузере или через VS Code Live Server.
Главная работает локально: Bootstrap, логотип и постеры включены в репозиторий.
Дизайн: белый фон, тёмный текст, терракотовый акцент, простые карточки и свободные отступы.

## Структура

- `cinema-ticketing/index.html` — Home: меню, форма поиска, четыре фильма и преимущества.
- `css/common.css` — общие цвета, кнопки, navbar, footer и адаптивное меню.
- `css/home.css` — только главная страница.
- `assets/images/` — логотип, favicon, постеры и их источники.
- `vendor/bootstrap/` — Bootstrap 5.3.8 и лицензия MIT.
- Остальные HTML/CSS-файлы — пока заготовки для следующих страниц.

HTML-файлы лежат в отдельной папке, поэтому общие ресурсы подключаются через
`../css/`, `../assets/` и `../vendor/`. Переходы между HTML-страницами используют
имена файлов без `../`.

## Работа вдвоём

Каждый участник редактирует свои HTML-страницы и соответствующие CSS-файлы.
Изменения `common.css` согласовывайте. На новых страницах подключайте Bootstrap,
затем `../css/common.css`, затем CSS конкретной страницы. Общую шапку, подвал
и окна Help/Terms можно скопировать из Home. Сохраняйте `id="cinema-page"` у `body`:
это ID для общих стилей кнопок. Перенесите `active`, `aria-current` и
`span.nav-underline` на текущий пункт меню.

## Функции и дальнейшее подключение

- Мобильное меню, Help и Terms работают через готовые компоненты Bootstrap.
- Форма Search отправляет GET на `movies.html` с параметрами `location`, `date`, `q`.
- `location`: `astana`, `almaty`, `shymkent`; `date`: `today`, `tomorrow`, `this-week`.
- Book tickets открывает `movie-details.html?movie=...`.
- Идентификаторы фильмов: `dune-part-two`, `inside-out-2`, `the-wild-robot`, `alien-romulus`.
- Каталог и страница фильма сейчас пустые: поиск и выбор билетов заработают
  после реализации этих страниц. Сама HTML-форма только передаёт параметры.
- My Tickets и Sign In пока отключены, так как личный кабинет не реализован.

## Что показано из курса

Семантический HTML (`header`, `nav`, `main`, `section`, `article`, `footer`),
форма с `label`, списки и изображения с `alt`; Bootstrap grid и utility-классы;
собственный Flexbox в подвале и карточках; CSS Grid в преимуществах;
relative/absolute positioning для линии под активным пунктом меню;
обычные media queries для планшетов и телефонов.
Карточки: четыре колонки от 992px, две от 576px, одна на узких экранах.

В собственных CSS-файлах нет CSS-переменных, `var()`, `clamp()`, `aspect-ratio`,
`object-fit`, `transition`, псевдоэлементов или дополнительных селекторов состояния.
Цвета записаны HEX-значениями. Заголовок: 48px на компьютере, 40px на планшете,
32px на телефоне. Постеры масштабируются через `width: 100%` и `height: auto`;
их исходные пропорции сохранены. Стандартные атрибуты `aria-*` оставлены для
доступности элементов и готовых компонентов Bootstrap. Собственного JavaScript нет.
Внутренний код Bootstrap может использовать более сложные возможности CSS/JS —
это код подключённой библиотеки, а не написанные участниками правила.

Для полного midterm ещё нужны остальные страницы, хотя бы одна HTML-таблица,
проверка переходов и публикация через GitHub Pages или Netlify.

Постеры и фильмовые данные используются для учебной демонстрации.
Источники и сведения о правах: `assets/images/posters/SOURCES.txt`.
Контактный адрес из макета демонстрационный. Реальные платежи и бронирование не выполняются.
